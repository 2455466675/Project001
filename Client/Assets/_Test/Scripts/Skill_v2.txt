================================================================================
回合制战斗设计大纲 v2.1
面向单机 PVE。在 Skill.txt(v1) 基础上重构，v2.1 强化破韧的难度、急切度与收益。
================================================================================

【v2 相对 v1 的改动】
1. 元素印记（原"元素附着"）与护体灵力从"互斥"改为"串联"：
   有灵力时也能累积印记（不触发反应），灵力被击破的瞬间集中引爆。
2. 五行关系细化为 5 种方向明确的关系，任何搭配都能推进，只是效率不同。
3. 元素反应从 2 条扩为 15 条，按五行规律分类（相克=破坏 / 相生=生产 / 同源=爆发）。
4. 状态效果拆为三类，控制类改回合数计并引入"定神"抗性递减。
5. 新增灵韵（技能资源）与 6 种行动方案。
6. 属性收敛：五种元素精通合并为一项；技能奥义必中，仅普攻可闪避；速度不再影响闪避。
7. 行动顺序改为当回合开始时计算，并向玩家预览未来 2 回合。
8. 护盾衰减计数记在角色身上，修掉"换盾刷新衰减"漏洞。
9. 补上物理侧独立 debuff 体系，使物理路线与元素路线对称。

【v2.1 的改动：把破韧从"堆数值"变成"限时解题"】
A. 护体灵力重构为「灵枢」：由若干个标注五行元素的节点按顺序排列，
   攻击只作用于当前最前的未破节点，节点元素决定本次攻击的破韧效率与减伤。
   → 每破掉一个节点，最优元素就换一次。玩家每回合都要重新做选择，
     单一元素队必然在某些节点上卡住，队伍元素多样性成为真实需求。
B. 新增「威压」系统：敌人公开宣告一个将在 N 次行动后发动的大招，
   效果与倒计时全程可见。玩家必须在倒计时归零前完成破韧才能破除它。
   → 破韧从"迟早能做到的事"变成"有截止时间的任务"，急切度来自可预期的威胁。
C. 破韧收益大幅提升，且与"提前量"挂钩：
   剩余倒计时直接转化为崩势窗口的额外回合数。打得越好，爽点越长。
D. 新增「势」：连续破除威压技累积全队增益，一次失手清空。
E. 控制类与顺序干涉类技能获得战略地位：敌人不行动则倒计时不递减，
   即"控一回合 = 多一回合破韧时间"，但受定神抗性限制，无法滥用。
F. 失手有明确的追回路径（力竭窗口 + 资源补偿 + 灵枢削减），痛但不崩盘。
G. 节奏基准反转：v2 的"复原恢复 60% 让战斗逐轮加速"改为逐轮变奏加难
   （节点数增加、元素重排、倒计时缩短、威压技升级）。


================================================================================
一、设计目标与核心循环
================================================================================

【体验目标】
每个精英与 Boss 都是一道有截止时间的题。玩家读懂它的灵枢构成与威压威胁，
用有限的行动次数在倒计时内完成破韧。破得早，收益翻倍；破得晚，只能勉强过关；
破不了，就得硬吃一发大招然后想办法追回来。

乐趣来源不是"能不能破"，而是"能提前多少破"。

【核心循环（威压周期）】
    宣告   → 敌人公开威压技名称、效果与剩余行动次数（倒计时）
    解题   → 读取灵枢节点序列，选择技能击碎节点；同时累积元素印记
    引爆   → 最后一个节点破碎，印记引爆，威压技被破除，敌人进入崩势
    收割   → 崩势期敌人无法行动、易伤 +30%；窗口长度 = 1 + 剩余倒计时
    变奏   → 敌人复原，灵枢重排并加难，宣告新的威压技 → 回到"解题"

    失手分支：
    倒计时归零 → 威压技发动 → 敌人力竭 1 回合（灵枢削减、易伤）
               → 玩家获得资源补偿 → 追回或崩盘

【三条并行路线】
    元素破韧    靠相克关系高效击碎节点，破韧最快，但受节点元素限制
    暴击破韧    物理路线。暴击时裂痕翻倍，不看节点元素，靠暴击率构筑
    铺垫特化    "泄气"关系无法破韧但攒印记层数与灵韵，
                队伍里带 1 名专职铺垫者可让引爆威力翻倍


================================================================================
二、战斗流程与结算时序
================================================================================

【单回合时序（严格按此顺序结算）】
    R1. 回合开始
    R2. 护盾衰减结算
    R3. "回合开始时"类效果结算（再生、复原完成判定、力竭结束判定）
    R4. 计算本回合行动顺序（按当前速度快照；本回合内不再因速度变化重排，
        但可被技能显式改变：前移 / 后移 / 移除 / 追加）
    R5. 依次行动：
        行动前 → 判定控制状态（眩晕/昏睡/冻结跳过，混乱随机行动）
        行动   → 结算命中、伤害、裂痕、节点破碎、印记、反应
        行动后 → 若行动者持有威压条且本次行动已完成，威压倒计时 -1
                 → 若倒计时归零，标记"下次行动发动威压技"
    R6. 全员行动完毕 → 回合结束结算，依次：
        a) 持续伤害与治疗（流血 → 中毒 → 燃 → 再生）
        b) 元素印记固有效果结算
        c) 灵枢重铸判定（若敌人有此特性且本回合未被击碎任何节点）
        d) 增减益类 buff 剩余回合数 -1
        e) 控制类剩余回合数 -1
        f) 持续伤害类层数按各自规则递减
    R7. 回合结束 → 下一回合

【关键时序说明】
    - 威压倒计时绑定"敌人的行动次数"，不绑定回合数。
      因此让敌人跳过行动（眩晕/冻结/移除行动/紊乱）就能延缓大招。
      UI 文案应写作「威压：还需行动 3 次」而不是「3 回合后」。
    - 崩势期间敌人不行动，倒计时自然停滞（但威压技此时已被破除）。

【行动顺序规则】
    - 顺序 = 速度降序；相同时按 队伍(玩家优先) → 站位序
    - 顺序在 R4 计算，上一回合施加的减速在下一回合立即生效
    - UI 展示当前回合完整顺序 + 未来 2 回合预测，且在敌人图标上标注威压倒计时
    - 顺序干涉类效果（前移/后移/移除/追加）立即在 UI 可见。
      「移除敌人本回合行动」= 威压倒计时不递减，这是该类技能的核心战略价值。


================================================================================
三、属性系统
================================================================================

【可养成属性（10 项 + 1）】
    最大生命值
    物理攻击力    影响物理技能伤害
    元素攻击力    影响元素技能伤害
    物理防御力    减免物理伤害
    元素防御力    减免元素伤害
    速度          决定行动顺序（不影响闪避）
    命中          仅影响普攻命中率
    闪避          仅影响被普攻命中的概率
    暴击率        造成暴击的概率。暴击时对灵枢造成的裂痕翻倍（破韧的第二条路径）
    暴击伤害      暴击伤害倍率（基础 175%）
    元素精通      单一数值。影响元素反应强度、元素印记固有效果强度、引爆威力。
                  不影响元素技能基础伤害（与元素攻击力分离乘区）

    → v1 的"五行各一份精通、且同时管攻与防"造成 10 个语义重叠的养成维度，
      玩家无法估值、策划无法调参。此处收敛为 1 项："元素精通 = 玩反应的能力"。

【非养成属性（关卡设计参数，仅敌人持有）】
    五行抗性（金/木/水/火/土）      制造关卡差异
    灵枢配置（节点数、元素序列、特性）  破韧解法的核心变量
    威压配置（技能类型、倒计时长度）    施压强度的核心变量
    元素亲和                         该敌人使用哪些元素攻击

【元素亲和（角色标签，非数值）】
    每个角色固有 1～2 种元素亲和，决定它能施加哪种元素印记、
    以及它对哪些灵枢节点高效。这是队伍搭配的主要抓手。


================================================================================
四、资源与行动方案
================================================================================

【灵韵】技能资源
    每角色独立。上限 10，战斗开始 3。
    获取：普攻 +2、凝神 +3、蓄势 +1、被击中 +1（每回合上限 +2）、
          "泄气"关系攻击 +2、"汲取"关系攻击 +1、
          破除威压技时全队 +3、威压技发动时（失手补偿）全队 +3
    消耗：技能消耗 1～4 点。

【奥义值】爆发资源
    每角色独立 0～100。造成/受到伤害按比例累积，触发元素反应 +15，
    破除威压技时全队 +20，威压技发动时全队 +25。
    满值可释放奥义（占用行动，不消耗灵韵，释放后清零）。

【行动方案（每回合选择其一）】
    1. 普攻    不消耗灵韵，+2 灵韵，低倍率，可被闪避
    2. 技能    消耗灵韵，必中，核心手段（伤害/破韧/印记/增益/顺序干涉/控制）
    3. 奥义    需奥义值满，必中，高威力，通常自带高额裂痕或强制破节点效果
    4. 凝神    本回合受到伤害 -40%，+3 灵韵，并解除自身 1 个可解除的负面效果
    5. 蓄势    本回合不行动。下回合首个技能威力 +60% 且必定暴击（因此裂痕翻倍）；
               本回合若受到直接伤害则加成减半
    6. 道具    每回合限 1 次，不占用行动（可与上述任一项共存）
               道具库中应包含"灵枢探查"（揭示隐匿节点）一类的解题工具

    → 凝神自带解负面，是全队通用的解控/解毒手段，
      解决 v1 中"debuff 只能施加不能解除"的单向滚雪球。
    → 蓄势必定暴击 = 裂痕翻倍，使其成为破韧的爆发手段，
      与"顺序干涉"配合可制造"蓄势者前移，一击破掉最后节点"的连携。

【技能标签（与破韧相关）】
    破势    对当前节点造成额外固定裂痕，不受元素关系影响（物理角色的破韧手段）
    贯穿    裂痕溢出时可结转到下一个节点（否则溢出丢弃）
    撼灵    直接击碎当前节点（高灵韵消耗，通常为奥义级，全队应稀缺）
    窥灵    揭示灵枢中的隐匿节点
    锁行    移除敌人本回合行动（延缓威压倒计时，不属于控制类、不吃定神抗性，
            但自带 CD 且全队数量应稀缺）


================================================================================
五、五行关系与破韧判定
================================================================================

【五行基础】
    相生链：木 → 火 → 土 → 金 → 水 → 木     （读作"木生火"）
    相克链：木 → 土 → 水 → 火 → 金 → 木     （读作"木克土"）

【关系判定】
    比较对象是「攻击元素 A」与「当前灵枢节点的元素 D」。
    注意：不是与敌人整体比较。节点推进 → 判定基准改变 → 最优技能改变。

    v1 只写了"相生/相克"两个词，方向不明确（木灵力被土打与被金打效果应完全相反）。
    此处细化为 5 种，方向明确、可直接查表：

    关系   条件      含义            伤害减免  裂痕   附加
    --------------------------------------------------------------------------
    相克   A 克 D    正解，以克破之   25%      +3     印记额外 +1 层
    汲取   D 生 A    借力，次优解     40%      +2     攻方 +1 灵韵
    反噬   D 克 A    被节点压制       55%      +1     无
    同源   A == D    同性相斥         50%      +1     印记层数上限 +1
    泄气   A 生 D    喂养节点，最差   70%      +0     攻方 +2 灵韵
                                                     印记额外 +2 层
    物理   —         无五行关系       35%      +1     不可施加印记
                                                     暴击时裂痕翻倍

    - 暴击对任何关系都使裂痕翻倍（相克暴击 = +6）
    - "破势"标签技能额外附加固定裂痕，不受关系影响
    - 节点韧度统一为 6（见第六节），因此：
        相克     2 次攻击破 1 节点
        汲取     3 次
        同源/反噬/物理  6 次
        泄气     永远无法破节点
      → 梯度明显（3 倍差距），构筑与选技能的回报清晰可感。

【查表示例（当前节点 D = 木）】
    A = 金 → 金克木 → 相克（裂痕 +3，减伤 25%）      ← 该打这个
    A = 火 → 木生火 → 汲取（裂痕 +2，减伤 40%，+1 灵韵）
    A = 土 → 木克土 → 反噬（裂痕 +1，减伤 55%）
    A = 木 → 同源（裂痕 +1，减伤 50%）
    A = 水 → 水生木 → 泄气（裂痕 +0，减伤 70%，+2 灵韵，印记 +2 层）
                       ← 破不了韧，但这一击是在为引爆攒层数

【关于"泄气"】
    v1 的"相生减伤 80% 且为敌人回复 1 单位灵力"会让错误搭配彻底卡死，
    玩家学到的结论是"每关只有一套正确队伍"，构筑僵化。
    v2.1 把泄气改造成一条明确的功能位：它完全不参与破韧，
    但提供最高的印记层数增长与灵韵回收。
    队伍里带 1 名专职泄气者，是提升"引爆威力"的主要手段。
    → 破韧者与铺垫者的分工，是本设计的队伍构筑核心。


================================================================================
六、护体灵力：灵枢系统
================================================================================

（替代 v1 的"护体灵力单位"与 v2 的单一数值条）

【结构】
    敌人的护体灵力由 N 个「灵枢节点」按固定顺序排列构成，
    每个节点标注一种五行元素。示例：

        [ 火 ] [ 水 ] [ 水 ] [ 金 ] [ 木 ]
          ▲
        当前节点（裂痕 4 / 6）

    - 攻击只对「当前最前的未破节点」造成裂痕
    - 节点韧度统一为 6 点裂痕
    - 裂痕达到 6 → 节点破碎，裂痕清零，指针推进到下一节点
      （裂痕溢出默认丢弃，仅"贯穿"标签技能可结转）
    - 全部节点破碎 → 护体灵力崩溃 → 引爆元素印记 → 敌人进入「崩势」

【为什么用有序节点而不是单一数值条】
    1. 每破一个节点，最优元素就换一次 → 玩家每回合都要重新决策，
       而不是开局算一次就照公式打完。这是对"公式化战斗"的直接解法。
    2. 单一元素队必然在某些节点上效率骤降（同源只 +1），
       元素多样性成为真实需求，而不是靠数值强行要求。
    3. 节点序列是可读的信息，玩家能预判"再打 2 下就轮到我的火角色上场"，
       形成短期计划 → 中期计划 → 威压截止的三层规划结构。

【伤害减免】
    敌人在灵枢未崩溃期间，按「当前节点元素」与攻击元素的关系减免伤害
    （第五节表格）。因此敌人的防御倾向随节点推进而变化：
    同一个技能在不同节点阶段的输出效率不同，玩家需要动态调整输出顺序。

【灵枢配置参数（敌人设计维度）】
    节点数        普通 0（不带灵枢）/ 精英 4～5 / Boss 每段 5～7
    元素序列      决定解法。不应出现"全部同元素"（会退化成唯一解）
    节点韧度      默认 6。可为个别节点单独调高（"核心节点"）
    隐匿          节点元素不可见，需用"窥灵"标签技能或道具揭示。Boss 变体使用
    顺序锁        破节点时若当前节点未破而攻击了后续节点，无效（默认即为顺序推进）
    重铸          回合结束时（R6-c）若本回合未击碎任何节点，当前节点裂痕减半。
                  高压敌人特性，迫使玩家维持每回合的破韧产出，杜绝"慢慢磨"
    护法          场上存在特定小怪时，灵枢免疫裂痕。必须先清小怪

【灵枢的 UI 要求（不可省略）】
    - 完整节点序列与各节点元素常驻可见（隐匿节点显示为"？"）
    - 当前节点的裂痕进度条，且在玩家选择技能时预览"这一击会造成多少裂痕"
    - 明确标注该技能对当前节点的关系（相克/汲取/…），用颜色区分
    → 破韧是解题玩法，信息必须完全公开，难度来自资源与时间限制，不能来自信息缺失
      （"隐匿"是刻意设计的例外，且必须提供揭示手段）

【复原与变奏】
    崩势结束后的第一个回合，敌人进入「复原中」，该回合：
        - 排在行动队列首位，行动为"凝聚"（不攻击）
        - 回合结束时（R6 之后）完成复原：灵枢重建，并执行「变奏」
        - 复原完成时清除自身全部元素印记，并清空自身"定神"层数

    【变奏规则（逐轮加难）】
        - 节点元素序列重新排布（不是简单还原）
        - 节点数 +1（有上限，建议不超过 8）
        - 威压倒计时 -1（有下限，建议不低于 3）
        - 威压技升级为更高阶版本或更换类型
        - Boss 后期段可能同时挂两条威压条

    → v2 原本设定"复原恢复 60% 使战斗逐轮加速"，方向与本次目标相反，已废除。
      现在每一轮都比上一轮更紧，玩家的构筑与操作水平决定他能撑过几轮。

【打断复原】
    在"复原中"回合内，对该敌人累计造成 ≥ 其最大生命值 X%（建议 12%）的伤害，
    或使用带"打断"标签的技能，则复原失败：
        收益：崩势延长 1 个完整回合（多一轮 +30% 易伤 + 输出窗口）
        代价：该敌人下回合排在队首，并获得一次「强化行动」

    → v1 的"打断后敌人获得两次行动机会"会让玩家算出"永远不要打断"，机制作废。
      改为一次强化行动，使"多 1 回合窗口 vs 吃一次强攻"成为真实的赌注。

【关于玩家角色的灵枢】
    玩家角色不设灵枢。玩家可通过特定角色/装备主动获得护体灵力作为防御手段，
    但被击破时只失去当前回合行动，且不进入崩势易伤状态。
    → v1 若玩家走同一套规则，被破韧即损失 2 回合行动，
      在回合制里极易形成不可挽回的雪球式崩盘。


================================================================================
七、威压系统（大招预告与打断）
================================================================================

这是 v2.1 新增的核心系统，作用是给破韧一个截止时间。

【基本规则】
    - 精英与 Boss 持有「威压条」，普通小怪不持有
    - 战斗开始时（或进入新阶段时）敌人宣告一次威压技，公开三项信息：
        技能名称 / 效果摘要 / 剩余行动次数（倒计时，建议初值 3～6）
    - 倒计时在该敌人每次完成一次行动后 -1（时序见 R5）
    - 倒计时归零后，该敌人的下一次行动即为发动威压技（替代普通行动）
    - 在倒计时归零前使其灵枢崩溃 → 威压技被「破除」

【为什么倒计时绑定"行动次数"而不是"回合数"】
    让"阻止敌人行动"成为延缓大招的合法手段，从而：
    - 控制类技能（眩晕/冻结）获得战略地位：控一回合 = 多一回合破韧时间，
      但受「定神」抗性限制（3 层免疫，敌人复原时才清空），因此不可滥用，
      玩家必须决定"这次控制留到哪一轮用"。这是全局资源管理，不是常规操作。
    - 顺序干涉类技能（移除行动）从"锦上添花"变成关键手段
    - 高速敌人在一回合内行动多次时，倒计时消耗更快，压力自然更大

【威压技类型库（策划模板）】
    类型      效果                                      玩家应对
    --------------------------------------------------------------------------
    灭杀式    全体高额伤害，可能造成一至两名角色阵亡      硬吃需盾/减伤/治疗准备
    侵蚀式    全体施加重度负面（破甲+创伤+减速，5 回合）  硬吃后续极其难受
    狂暴式    自身获得巨额增益并立即重建灵枢              必须打断
    封印式    封锁玩家某类行动若干回合（禁技能/禁奥义）    必须打断
    剥夺式    清除玩家全部增益与护盾，并夺取全队灵韵      必须打断
    增援式    召唤护法小怪（护法在场时灵枢免疫裂痕）      必须打断或立刻清场

    设计原则：
    - 灭杀式与侵蚀式是"可以选择硬吃但很痛"，给玩家用防御资源换时间的空间
    - 狂暴式、封印式、剥夺式、增援式是"必须打断"，用于制造真正的硬性门槛
    - 一场 Boss 战应混用两类：前期给可硬吃的，后期给必须打断的，
      让玩家在前期学会机制，在后期被真正考验

【破除的收益（第八节详述）】
    威压技取消 + 敌人进入崩势 + 崩势窗口按剩余倒计时延长 + 全队资源回馈 + 势 +1

【发动的后果与追回路径（失手保护）】
    威压技发动后：
        - 敌人进入「力竭」1 回合：速度 -50%，受到伤害 +20%，无法行动
        - 敌人灵枢立即损失 40% 的节点（从当前节点起向后计算，向下取整）
        - 玩家全队 +3 灵韵、+25 奥义值
        - 玩家全队获得 1 层「不屈」：受到伤害 -15%（3 回合）
        - 该敌人重新宣告下一个威压技，倒计时 +1（比原本更宽松）
        - 玩家的「势」清空

    → 失手是"痛，但立刻拿到一批资源和一个明显更容易的下一轮"，
      不是死亡螺旋。玩家会想"再来一次我能赶上"，而不是"这局完了"。
    → 连续失手时威压技强度会阶梯提升，但设上限（建议 3 阶封顶），
      避免不可逆的雪崩。

【最后一击窗口（高光时刻设计）】
    倒计时降至 1 时，敌人进入「凝威」状态，该回合内：
        - 敌人受到的裂痕 +50%（向上取整）
        - 敌人受到的伤害 +15%
        - UI 进入高压表现（红色描边、心跳音效、时间压迫感）
    → 这是刻意留出的翻盘窗口。让"最后一刻救回来"在数学上真的可行，
      玩家会反复回味这种时刻。没有这个窗口，踩线失败只会让人觉得差一点点很憋屈。

【多威压并行】
    同一场战斗最多同时存在 2 条威压条（仅 Boss 后期段使用）。
    两条威压条共享同一个灵枢：破韧一次只能破除其中一条（玩家选择破哪条），
    另一条继续倒计时。
    → 制造"救不了全部，选一个"的两难，这是 Boss 战后期的情绪高点。


================================================================================
八、崩势与破韧收益
================================================================================

（"崩势"即 v1 的"灵力紊乱"，改名以贴合灵枢崩溃的表达）

【触发瞬间的结算顺序】
    1. 引爆当前元素印记（第十节）
    2. 破除该敌人当前的威压技（多威压时由玩家选择破除哪一条）
    3. 计算崩势窗口长度
    4. 若该敌人本回合尚未行动，立即从队列移除
    5. 全队资源回馈：+3 灵韵、+20 奥义值
    6. 「势」+1（第九节）
    7. 进入崩势

【崩势窗口长度 = 1 + 破除时的剩余倒计时（上限 +3）】
    倒计时剩余 3 破除 → 崩势 4 回合
    倒计时剩余 1 破除（踩线）→ 崩势 2 回合

    → 这是本设计最重要的正反馈闭环：把"你打得多好"直接换算成"你能爽多久"。
      构筑到位、选技能正确、把控制资源用在对的时机，回报是成倍的输出窗口。
      而不是 v1 那种"不管怎么破，窗口都是固定 2 回合"。

【崩势状态效果】
    - 无法行动（整个窗口期间）
    - 受到的所有伤害 +30%
    - 玩家全队对其暴击率 +15%
    - 元素印记可正常触发元素反应（铺垫期不触发，见第十节）
    - 可被控制类效果完整影响（用于在窗口结束后继续拖延复原）
    - 灵枢在崩势期间不存在，因此不再有五行减伤

【破韧的完整收益清单（用于评估收益是否够大）】
    即时   印记引爆（本设计最高单次伤害）
    即时   威压技取消（规避一次全队级威胁）
    即时   全队 +3 灵韵、+20 奥义值（让收割期能连放大招）
    窗口   1 + 剩余倒计时 回合的完全免费输出期，期间易伤 +30%、暴击 +15%
    长期   「势」+1，全队永久增益累积（本场战斗内）
    附加   复原回合可选择打断，再换 1 回合窗口

    → 收益从"一个 30% 易伤的短窗口"扩展为"伤害爆发 + 威胁规避 + 资源回收
      + 长窗口 + 长期增益"五重叠加。破韧值得玩家把一切资源都押上去。


================================================================================
九、势（连破奖励）
================================================================================

    - 每成功破除一次威压技 → 全队获得 1 层「势」，上限 5 层
    - 每层势：全队造成的伤害 +6%，且所有攻击对灵枢的裂痕 +1
    - 威压技成功发动（玩家失手）→ 势全部清空
    - 势在整场战斗内不自然衰减

    【设计意图】
    "裂痕 +1" 使势形成正向滚雪球：破得越多，后续破韧越快，
    从而对抗变奏带来的难度递增。这让长线战斗（Boss）有明确的成长曲线：
    前期艰难 → 中期建立势 → 后期在更难的变奏下依然能维持破韧。

    而一次失手清空全部势，意味着后期失手的代价极高（同时失去 30% 伤害与破韧速度），
    形成"越到后面越不能出错"的紧张感，且这个紧张感是玩家自己积累出来的，
    不是策划硬塞的数值墙。

    UI：势的层数应显示在屏幕显著位置并有明确的获得/清空表现。


================================================================================
十、元素印记
================================================================================

（对应 v1 的"元素附着"，合并了 v1 的"附着强化"，取消两级结构）

【基础规则】
    - 元素攻击命中时对目标施加对应元素的印记（物理攻击不施加）
    - 同一目标同时只存在一种元素印记
    - 基础层数上限 5；崩势状态下上限 7；"同源"关系攻击使上限 +1
    - 印记不随回合自然衰减，只在下列情况消失：
        a) 触发元素反应（消耗全部层数）
        b) 被引爆（消耗全部层数）
        c) 目标完成复原
      → v1 的"每回合 -1 层"与"需要多次攻击才能触发反应"直接冲突，
        使铺垫被时间打消。取消自然衰减后，铺垫成为可靠投资，
        这也是"泄气"路线能作为一个功能位存在的前提。

【施加不同元素印记时的分支】
    情况 A：目标灵枢未崩溃（铺垫期）
        不触发反应。原印记发生「转化」：变为新元素印记，层数 = 原层数 - 1（最低 1）。
        → 铺垫期的决策是"用哪个元素、攒到几层来完成最终引爆"。
          频繁换元素会掉层，鼓励规划。
        → 这也与灵枢形成有趣的张力：破韧需要跟着节点换元素，
          攒印记却希望元素稳定。玩家要在"破得快"和"引爆狠"之间取舍。
          这是 v2.1 里我最看重的一处决策张力。

    情况 B：目标处于崩势（无灵枢）
        立即触发元素反应（第十一节），消耗全部层数。

    情况 C：施加同元素印记
        层数 +1。达到层数上限时触发「同源爆发」（第十一节）。

【引爆】
    击碎最后一个灵枢节点的那一击，若目标身上存在元素印记，立即引爆：
        以"击碎那一击的元素"与"印记元素"进行一次元素反应结算
        威力 = 反应基础威力
               × (1 + 0.15 × 印记层数)
               × (1 + 0.10 × 该敌人本轮灵枢节点总数)     ← 越硬的敌人引爆越强
               × (1 + 元素精通系数)
        两者同元素 → 视为同源爆发，威力按层数计算
    引爆是全设计最大的单次爽点，表现必须做足（顿帧、镜头、全屏特效、分段数字）。

【元素印记的固有效果（层数 N，回合结束结算）】
    火印（燃）  回合结束受到 最大生命值 0.5%×N 的火元素伤害。
                吃元素抗性与元素精通，不被护盾吸收，不解除昏睡、不击碎冻结。
    水印（濡）  受到的元素反应效果 +15%×N；元素防御力 -3%×N。
    木印（缚）  速度 -4%×N；闪避 -3%×N。
                （因顺序改为当回合计算，下回合即生效；减速还能推迟敌人行动，
                  从而间接延缓威压倒计时）
    金印（锐）  受到的物理伤害 +4%×N。
    土印（凝）  受到的所有伤害 -3%×N，但每次被攻击时对灵枢额外造成 1 点裂痕。
                → 双刃印记：想加速破韧就堆土印，代价是这段时间打不痛。
                  在有威压倒计时的前提下，这个取舍变得非常尖锐：
                  是牺牲伤害换取赶上截止时间，还是赌自己不需要它。


================================================================================
十一、元素反应
================================================================================

【结构】按五行规律分为三类，规律性强，玩家易记：
    相克组（5 条）= 破坏型：高倍率伤害 + 削弱
    相生组（5 条）= 生产型：为攻方提供增益 / 回复 / 铺垫扩散
    同源组（5 条）= 满层爆发：单元素专精的专属奖励

    所有反应数值均受「元素精通」加成（统一乘区），
    避免 v1 中"结晶吃精通、蒸发不吃精通"造成的养成不对称。

--------------------------------------------------------------------------------
【相克组 · 破坏型】
--------------------------------------------------------------------------------
    水 + 火 = 蒸腾
        本次元素伤害 ×180%（多段攻击仅增幅触发的那一段）。
        目标带水印（濡）时倍率提升至 250%。

    火 + 金 = 熔刃
        本次元素伤害 ×160%。目标物理防御力 -25%（3 回合）。
        攻方获得「锋锐」：下一次攻击必定暴击（因此裂痕翻倍）。

    金 + 木 = 斫伐
        本次元素伤害 ×150%。目标命中 -30%（3 回合），并施加流血 3 层。

    木 + 土 = 蚀根
        本次元素伤害 ×130%。目标物理防御力与元素防御力各 -20%（3 回合）。

    土 + 水 = 淤塞
        本次元素伤害 ×130%。目标速度 -30%（3 回合），
        并在当前行动队列中后移 1 位。
        → 后移可能使敌人本回合行动落到玩家全员之后，
          在威压倒计时紧张时这是实打实的一回合。

--------------------------------------------------------------------------------
【相生组 · 生产型】
--------------------------------------------------------------------------------
    木 + 火 = 燎原
        对目标造成火元素伤害，并对全体敌人施加 2 层火印。
        → 多目标战的开局铺垫手段。

    火 + 土 = 熔铸
        攻方全体获得元素护盾（盾值随元素精通与印记层数），
        并提升元素攻击力 25%（3 回合）。
        → 应对"灭杀式"威压技的主要预防手段。

    土 + 金 = 淬锐
        攻方全体提升物理攻击力 20%、暴击伤害 25%、暴击率 15%（3 回合）；
        目标物理防御力 -30%（3 回合）。
        → 暴击率提升 = 裂痕翻倍概率提升，这是物理破韧路线的核心增益来源，
          让物理队有理由带元素角色。

    金 + 水 = 涌泉
        攻方全体回复 3 点灵韵，并回复生命（随元素精通）。

    水 + 木 = 滋荣
        攻方全体获得再生（3 回合），
        并将目标身上的印记以 2 层的形式扩散到其他敌人。

--------------------------------------------------------------------------------
【同源组 · 满层爆发】（印记达上限时自动触发，消耗全部层数）
--------------------------------------------------------------------------------
    火 · 燔燎    高倍率火元素伤害 + 高层数燃
    水 · 涵渊    中等水元素伤害，目标元素防御力大幅降低，全队回复灵韵
    木 · 蔓生    中等木元素伤害，目标眩晕 1 回合（受定神抗性影响，可延缓威压）
    金 · 肃锋    高倍率物理+金混合伤害，无视目标 40% 物理防御，对灵枢造成 4 点额外裂痕
    土 · 磐固    攻方全体获得全能护盾，本回合内攻方伤害 +20%

--------------------------------------------------------------------------------
【多段攻击通则】
--------------------------------------------------------------------------------
    - 每段独立判定命中与伤害
    - 反应在第一段满足条件时触发，仅该段享受反应倍率；
      印记层数在第一段结算后即被消耗，后续段按普通伤害结算
    - 裂痕每段独立累积，因此多段攻击是高效破韧手段（其设计定位）
    - 若某一段击碎了当前节点，后续段作用于下一个节点，
      关系判定按新节点重算 → 多段技能的裂痕效率与节点序列相关，有额外深度


================================================================================
十二、状态效果（三类，规则彼此独立）
================================================================================

（v1 把所有状态统一用"层数上限 9"表达，导致可叠 9 回合眩晕这类必杀级问题，
  也让"层数"一个概念承担了过多语义。此处拆为三类。）

--------------------------------------------------------------------------------
【第一类：增减益】层数 + 独立持续回合
--------------------------------------------------------------------------------
    - 作用于战斗属性（攻/防/速/命中/闪避/暴击等）
    - 层数上限 5，每层线性叠加
    - 每层有独立的剩余回合数，回合结束各自 -1，归零单独移除
    - 同名增益与减益同时存在时，先各自求和再合并，不互相抵消移除
    - 物理侧专属：破甲（物防降低）、创伤（受治疗效果降低）

--------------------------------------------------------------------------------
【第二类：持续结算】层数，回合结束时结算
--------------------------------------------------------------------------------
    效果  伤害类型  被护盾吸收  层数递减    备注
    ------------------------------------------------------------------------
    流血  物理      否          结算后 -1   物理路线主力 dot，吃破甲加成
    中毒  无属性    否          结算后 -1   完全无视一切防御与抗性
    燃    火元素    否          不递减      由火印提供，随印记存续
    再生  治疗      —           结算后 -1   —

    - 层数上限 9（此类是线性伤害而非剥夺行动，可以高层数）
    - 持续伤害不解除昏睡、不击碎冻结、不触发受击类被动
      （否则玩家自己的 dot 会破掉自己施加的控制）
    - 持续伤害不对灵枢造成裂痕（否则破韧可以挂 dot 自动完成，绕过解题玩法）

--------------------------------------------------------------------------------
【第三类：控制】回合数计，不可叠层，受"定神"抗性约束
--------------------------------------------------------------------------------
    眩晕  无法行动
    昏睡  无法行动。受到任意"直接伤害"时立即解除（持续伤害不解除）
    混乱  不受控制，随机选择行动与目标（UI 必须给出强提示）
    冻结  无法行动。受到火元素伤害时被击碎：立即解除并额外承受一次水元素伤害。
          受到其他类型伤害时不解除，但该次伤害 +20%。
          → v1 写的"额外冰元素伤害"在五行体系里不存在冰；
            且"任意伤害击碎、火除外"与直觉相反。此处改为火解冻。

    【通用规则】
    - 以剩余回合数计（通常 1～2），不叠层，重复施加取较长者
    - 无法行动类控制不可并存，新的替换旧的
    - 施加时若目标本回合尚未行动 → 本回合即生效；
      若目标本回合已行动完毕 → 从下回合起生效（时长不变）
      → 修掉 v1 中"同一个 1 层眩晕因施加时机不同价值差一倍"的时序漏洞
    - 灵枢未崩溃的敌人对"无法行动类"控制有天然抗性：
      效果转为等值的属性削弱，不跳过行动
      → 这是为了保护破韧玩法本身：否则玩家可以在铺垫期直接控死敌人，
        威压倒计时永不推进，整套施压设计失效

    【定神（控制抗性递减）】
    - 每次成功被施加"无法行动类"控制后获得 1 层「定神」
    - 每层使后续控制命中率 -35%，3 层时免疫无法行动类控制
    - 战斗内不自然消失；敌人完成一次「复原」时清空
      → 因此控制是一种"每轮限量"的战略资源：
        一个威压周期内玩家大约只能成功延缓 2 次敌人行动。
        用在什么时候（早点拖延，还是留到凝威回合救命）是核心决策之一。

    【控制与威压的交互（重要）】
    - 敌人被控制而跳过行动 → 威压倒计时不递减
    - 崩势期间敌人本就不行动，此时施加控制的意义在于
      延长"崩势结束后到复原完成"之间的时间


================================================================================
十三、护盾
================================================================================

【类型】
    全能护盾  吸收物理与元素伤害
    物理护盾  仅吸收物理伤害
    元素护盾  仅吸收元素伤害
    - 中毒、流血、燃 等持续伤害不被任何护盾吸收

【唯一性与覆盖】
    每角色同时只能存在一个护盾。
    施加新护盾时：同类型 → 盾值相加；不同类型 → 移除原护盾，施加新护盾（盾值不继承）

【衰减】
    衰减计数记录在「角色」身上，而非护盾身上。
    每回合开始（R2）若角色存在护盾，按其当前衰减计数结算：
        第 1 次：盾值变为剩余的 70%，计数 +1
        第 2 次：盾值变为剩余的 40%，计数 +1
        第 3 次：盾值归零，护盾移除
    衰减计数在「角色身上完全没有护盾」时重置为 0。

    → v1 中"换不同类型护盾会重置衰减次数"可被利用为每回合换类型让盾永不衰减；
      而"同类型叠加不重置计数"又让后期补盾几乎无效，
      使依赖护盾存续的结晶体系被自己掐死。
    → 现规则下单盾最多存在 3 回合（防无限盾），断盾后可重新起盾并重新计数
      （盾流构筑成立）。盾队的玩法是"管理起盾节奏"，
      具体来说是"把新盾留到威压技发动的那一回合"，
      这让护盾与威压系统直接产生战术耦合。


================================================================================
十四、伤害计算
================================================================================

【顺序（乘法链）】
    1.  基础伤害      = 技能倍率 × 对应攻击力（物理 / 元素）
    2.  防御减免      × K / (K + 对应防御力)，K 为等级常数
    3.  灵枢减免      × (1 - 第五节表格减伤值)    ← 按当前节点元素判定，灵枢崩溃后不生效
    4.  五行抗性      × (1 - 目标对应抗性)         ← 仅元素伤害
    5.  增伤/易伤     × (1 + Σ增伤 - Σ减伤)        ← 含崩势 +30%、力竭 +20%、凝威 +15%、
                                                     势 +6%/层、金印、土印等
    6.  暴击          × 暴击伤害倍率（若暴击）
    7.  反应倍率      × 元素反应倍率 × (1 + 元素精通系数)
    8.  引爆加成      × (1 + 0.15×印记层数) × (1 + 0.10×节点总数)   ← 仅引爆时
    9.  随机浮动      × [0.95, 1.05]
    10. 护盾吸收      按类型扣减，溢出进入生命值

【裂痕计算（与伤害独立）】
    裂痕 = (第五节关系基础值 + 破势标签附加值 + 势层数 + 土印附加)
           × (暴击 ? 2 : 1)
           × (凝威状态 ? 1.5 : 1)      ← 向上取整
    - 裂痕与伤害数值完全解耦：一个低伤害的技能可以是优秀的破韧手段，
      反之亦然。这让技能设计空间翻倍，也让"破韧特化角色"能成立。

【命中】
    技能、奥义、反应伤害、引爆伤害、持续伤害：必定命中。
    仅普攻可被闪避：命中率 = 100% + (攻方命中 - 守方闪避) 换算，下限 55%。

    → v1 中所有攻击都可 miss，而本设计的破韧有硬性截止时间，
      一次 miss 可能直接导致吃到威压技，挫败感极强且不可控。
      把随机性收敛到低价值的普攻上，保留手感但不破坏策略兑现。
    → 速度不再影响闪避，避免速度成为"先手+生存"双收益的超级属性。


================================================================================
十五、敌人与关卡设计
================================================================================

【敌人分层】
    杂兵    无灵枢、无威压。纯资源与节奏调节，用于让玩家攒灵韵与奥义值
    精英    灵枢 4～5 节点，1 条威压条（倒计时 4～6），可硬吃型威压技为主
    Boss    分段灵枢 5～7 节点，逐段变奏加难，后期出现必须打断型与双威压

【敌人 AI 状态机】
    正常 →（灵枢崩溃）→ 崩势 → 复原中 →（成功）正常（变奏）
                                      →（被打断）崩势延长 → 强化行动 → 复原中
    正常 →（倒计时归零）→ 发动威压技 → 力竭 →（力竭结束）正常（重新宣告威压）

【关卡组合诉求（反公式化的四个正交变量）】
    1. 灵枢元素序列    决定"该带哪些元素角色"
    2. 灵枢特性        隐匿 / 重铸 / 护法 / 核心节点，决定"该带哪些功能位"
    3. 威压技类型      决定"该硬吃还是必须打断"，即防御资源如何分配
    4. 倒计时长度      决定"破韧的时间预算"，即能不能分心去做别的事

    四个变量组合出的题目彼此不同，同一套队伍与出招顺序无法通吃。
    这是本设计对抗"公式化战斗"的主要手段：
    不是靠增加数值，而是靠每场战斗改变"最优解的形状"。

【推荐节奏基准（用于调参）】
    杂兵战     2～3 回合
    精英战     8～12 回合，1～2 个威压周期
    Boss 战    20～30 回合，3～5 个威压周期
    首个威压周期  针对性配队应能提前 2 回合破韧；
                  非针对性配队应踩线或略微失手
    → 目标手感：默认打法会失手一次，玩家调整队伍与出招后能稳定提前破韧。
      失手是学习信号，不是惩罚。

【破韧难度校准参考（4 人队，节点韧度 6）】
    每回合队伍裂痕产出（不含暴击与势）：
        全相克配队        4 × 3 = 12   → 每回合破 2 个节点
        半针对性配队      3+3+1+1 = 8  → 每回合破 1.3 个节点
        完全不对位        4 × 1 = 4    → 每回合破 0.67 个节点
    面对 5 节点（总需 30 裂痕）：
        全相克      2.5 回合   → 大幅提前，崩势窗口拉满
        半针对      3.75 回合  → 踩线破除
        不对位      7.5 回合   → 失手，吃威压技
    → 3 倍的效率差距使配队与选技能的回报清晰可感，
      同时"不对位"也不是完全无法推进（约 7～8 回合仍能破），
      玩家吃一发大招后仍有追回空间。
